# Ky Laodou Othniela

Développeuse full-stack web et mobile, étudiante en Master 1 Informatique à l'IBAM (Université Joseph Ki-Zerbo, Ouagadougou).

Je conçois des applications de gestion complètes, de l'API à l'interface : gestion foncière, transport et logistique, restauration, gestion du courrier, simulation économique. J'aime aussi la donnée, la vision par ordinateur et l'infrastructure.

## Technologies

- **Front-end** : Angular · TypeScript · Tailwind CSS · Bootstrap · PWA
- **Back-end** : Laravel (PHP) · Spring Boot (Java) · FastAPI (Python) · Express.js
- **Mobile** : Flutter (Dart)
- **Données** : PostgreSQL · MySQL · Firestore · Dagster · TensorFlow · OpenCV · Pyomo
- **Temps réel et services** : Laravel Reverb · WebSocket · Firebase Cloud Messaging · Cloudinary
- **Infrastructure** : Docker · Vagrant · HAProxy · Prometheus · Grafana · GitHub Actions · Render

## Applications professionnelles

Réalisées pour des entreprises et organisations au Burkina Faso (code privé) :

- **Gestion foncière et immobilière** : lotissements, ventes, paiements échelonnés, documents signés électroniquement et vérifiables par QR code.
- **Gestion de flotte et de transport** : missions suivies en temps réel, logistique, facturation, application mobile du personnel.
- **Plateformes de restauration** : commande en livraison ou sur place, réservations, caisse, stock, notifications en temps réel.
- **Simulation économique** : plateforme web autour d'un modèle d'équilibre général calculable (EGC) des impacts du numérique.
- **Gestion du courrier** : réception, circuit de traitement, fiches signées, suivi par référence.
